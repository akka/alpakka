# Alpakka 11.0.x

## 11.0.0 (unreleased)

### Removed connectors

#### Pravega

The Pravega connector has been removed to reduce Alpakka's maintenance scope following
[Pravega's move to CNCF Archived status on September 23, 2025](https://www.cncf.io/projects/pravega/).

The `akka-stream-alpakka-pravega` artifact will no longer be published. Applications using this connector
must retain an existing release or maintain the connector separately.

#### IronMQ

The IronMQ connector has been removed to reduce Alpakka's maintenance scope. Its integration test job
and Docker services were already disabled.

The `akka-stream-alpakka-ironmq` artifact will no longer be published. Applications using this connector
must retain an existing release or maintain the connector separately.

#### Huawei Push Kit

The Huawei Push Kit connector has been removed to reduce Alpakka's maintenance scope.

The `akka-stream-alpakka-huawei-push-kit` artifact will no longer be published. Applications using this connector

#### Spring Web

The Spring Web connector has been removed to reduce Alpakka's maintenance scope. The connector targeted
Spring Framework 5.3 and Spring Boot 2.7.

The `akka-stream-alpakka-spring-web` artifact will no longer be published. Applications using this connector
must retain an existing release or maintain the integration separately.

See the [GitHub releases page](https://github.com/akka/alpakka/releases) for the complete list of changes.
